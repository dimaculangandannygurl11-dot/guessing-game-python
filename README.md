# Number Guessing Game

A console game in Python where the computer picks a secret number from 1 to 100 and you keep guessing until you get it.

## Features
- Tells you if your guess is too high or too low
- Counts your attempts
- Handles invalid input

## Built with
Python 3

## How to run
1. Clone this repository
2. Run `python guessing_game.py`

## What I learned
- Loops, user input, if/else and the random module
